Atlas Interior · Privacy Policy

Last updated: November 16, 2026

This policy describes how the Atlas Interior API client (Google Cloud project atlasinterior) uses YouTube API Services. The client is an internal tool operated solely by the owner of the YouTube channel Atlas Interior (youtube.com/channel/UCwobZmSm57JO-m07syIu1oA) to manage that channel only. It is not offered to the public and no other person can sign in to it.

YouTube API Services

This client uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also subject to the Google Privacy Policy.

What data is accessed

With the channel owner's authorization (OAuth 2.0), the client accesses only data belonging to the Atlas Interior channel:

  • basic channel information (channel ID, title and branding settings);
  • the channel's own videos and their metadata (titles, descriptions, tags, thumbnails, privacy status and scheduled publish times);
  • aggregated performance metrics of the channel's own videos, through the YouTube Analytics API (views, watch time, retention and similar reports);
  • public comments on the channel's own videos, solely so the owner can read and reply to them.

The client does not access, collect or store data about other YouTube users or channels beyond public search and video statistics used for topic research.

How the data is used

The data is used only to upload and schedule the channel's own videos, set their metadata, thumbnails, banner and watermark, reply to comments, and analyze the channel's own performance to plan future content. It is never sold, shared with third parties, or used for advertising.

Storage and security

OAuth credentials and access tokens are stored only on the channel owner's own computer, in a local folder excluded from version control, and are never transmitted to any server other than Google's. Analytics reports are kept locally as files for the owner's planning. No data is stored on third-party servers.

Revoking access and deletion

Access can be revoked at any time on the Google security settings page. After revocation, the client can no longer access any YouTube data, and the locally stored tokens and data can be deleted by the owner at any time. Stored API data is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.

Atlas Interior · Política de Privacidade

Atualizada em 16 de novembro de 2026

O cliente de API Atlas Interior (projeto atlasinterior no Google Cloud) é uma ferramenta interna, usada somente pelo dono do canal Atlas Interior no YouTube para gerenciar esse canal. Ele usa os Serviços de API do YouTube; ao usá-lo, você concorda com os Termos de Serviço do YouTube, e os dados acessados estão sujeitos à Política de Privacidade do Google.

Com a autorização do dono do canal, o cliente acessa apenas dados do próprio canal: informações básicas, vídeos e seus metadados, métricas agregadas do YouTube Analytics e comentários públicos nos vídeos do canal. Esses dados servem só para enviar e agendar vídeos, ajustar metadados, miniaturas, banner e marca d'água, responder comentários e analisar o desempenho do canal. Nada é vendido, compartilhado com terceiros ou usado para publicidade.

Credenciais e tokens ficam apenas no computador do dono do canal, fora do controle de versão. O acesso pode ser revogado a qualquer momento nas configurações de segurança do Google; depois disso, os dados locais podem ser apagados. Dados obtidos pela API são atualizados ou apagados em até 30 dias.
